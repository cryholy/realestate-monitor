# /rem-trend — on-demand 트렌드 판독 커맨드 설계

2026-07-31. 브레인스토밍·backtest 2회(급매·상대강도)를 거쳐 확정된 매수 framework v1을
세션 커맨드로 고정한다. 주간 푸시가 아닌 **호출식(pull)** — 긴급 이벤트는 기존
monitor cron + alert_rules가 이미 푸시하므로 역할이 겹치지 않는다.

## 목적

`/rem-trend` 호출 한 번으로 서울 9개 구 + 관심단지의 시장 판독문을 생성한다.
정체성: **"잘 사기(안 비싸게·강한 걸로·칼 피해서) 도구"이지 사이클 타이밍 신탁이 아니다.**
중립 원칙 — 신호와 판정 규칙만 제시, 매수/관망 단정 없음. LLM 산문 없음.

## 형태

- 파일: `~/personal-labs/.claude/commands/rem-trend.md` (rem-run.md와 동일 패턴)
- frontmatter: `description`, `argument-hint: "[telegram]"`,
  `allowed-tools`: Supabase MCP execute_sql + Bash(curl:*) (텔레그램 발송용)
- 실행 주체: 커맨드 지시문을 따라 세션의 Claude가 ①~④ SQL을 MCP
  `execute_sql`(project_id `flsbxpjywjuhylfwnrby`)로 실행 → ⑤ 판정 규칙을 기계적으로
  적용 → 판독문 조립.
- 출력: 기본 터미널. `$ARGUMENTS`에 `telegram` 포함 시 scratchpad에 파일로 쓴 뒤
  시스템 curl로 발송 (`.env`를 `set -a; . ./.env`로 로드, 토큰 미출력, 4,096자 확인,
  응답 `ok:true` 검증). 로컬 Python은 TLS 프록시에 막히므로 curl 고정.

## 판독문 5블록 (SQL은 커맨드 파일에 원문 고정)

검증 세션(2026-07-29~31)에서 실행·확인된 쿼리를 그대로 박제한다. 매번 즉흥 작성 금지
— "순진한 급매/구중위 착시" 재발 방지가 이 커맨드의 존재 이유.

| 블록 | 내용 | 핵심 가드 |
|---|---|---|
| ① 국면·상대강도 | 구별 84㎡ 동일단지 중위변화율, 최근 90d(−135~−45d) vs 이전 90d(−225~−135d), 내림차순 | 동일단지(same-store)만, 표본 <30단지 `⚠저신뢰`, 순진한 구중위값 착시 경고문 포함 |
| ② 거래량 | 9구 합산 월별 매매 12개월 | 최근 2개월 `[신고지연·과소]` 표기, 추세 판단은 완결 월만 |
| ③ 전세가율 | 구별 84㎡ 최근 수준 + 6개월 방향(Δ) | 매매·전세 동일 창(−135~−45d vs −225~−135d) |

| ⑤ framework 판정 | 후보별 A/B 트랙 상태표 → `대기`/`검토` | 아래 규칙표를 ①~④ 결과에 산술 적용 (추가 SQL 없음) |

## 판정 규칙 (framework v1 — backtest 2회 반영, 고정값)

**Track A — 기회 신호 (검토 착수 트리거)**
- A1 급매: 후보 최근 정상매물(3층↑·중개거래) 편차 ≤ **−8%** → *조사 플래그*
  (매수 트리거 아님 — backtest: 상승국면 회복률 58% < base 91%, 급매=약세 신호였음.
  "왜 이 단지만 약한가"를 확인하라는 뜻)
- A2 국면전환: 후보가 속한 구의 (ⅰ)동일단지 모멘텀이 이전창 ≤0 → 최근창 >0 전환
  **&** (ⅱ)최근 완결 2개월 평균 거래량 > 직전 3개월 평균

**상대강도(① 순위)는 트리거가 아니라 우선순위 결정에만 사용**
(backtest: 추세장 4/5 코호트 지속 ~1–4pp로 크기 작음, 전환점 1/5 역전 — 트리거로
쓰기엔 약하고, 전환 의심 시엔 아예 보류)

**Track B — 지뢰 게이트 (하나라도 걸리면 `대기`)**
- B1 떨어지는 칼: 구 동일단지 모멘텀 ≤ **−3%**
- B2 고가 매수: 후보 편차 ≥ **+3%**
- B3 쿠션 부족: 구 전세가율 < **0.40** & 방향 하락

**전환 의심 스위치**: ②에서 최근 완결 2개월 평균 거래량 < 직전 3개월 평균 × **0.7**
→ 판독문에 "전환 의심 — 상대강도 기반 우선순위 판단 보류" 경고 1줄. (2025-12
코호트에서 리더 역전을 재현한 국면. ponytail: 단순 임계 휴리스틱 — 레짐 레이어
도입 시 대체)

**판정**: B 전부 통과 && (A1 또는 A2) → `검토`, 그 외 `대기`. 후보 복수 `검토` 시
우선순위 = 상대강도 순위(전환 의심 시 제외) → 전세가율 두꺼운 순 → 편차 낮은 순.

## 고정 문구 (판독문 하단)

- 방식 요약 1줄: 동일단지 · 45일 신고지연 버퍼 · 저층/직거래 제외 · 중립(신호만)
- 한계 1줄: 14개월 데이터 — 국면·상대강도는 읽지만 절대 고점/저점(사이클)은 못 봄

## 에러 처리

- 블록별 독립: 쿼리 실패 시 해당 블록에 `— 조회 실패`를 표기하고 나머지는 계속
- ⑤는 의존 블록이 실패하면 해당 규칙만 `판정불가`로 표기
- 텔레그램 발송 실패(ok:false / 4,096자 초과): 터미널 출력은 유지하고 실패 사유 보고
